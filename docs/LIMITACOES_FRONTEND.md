# Limitações do frontend

- A recuperação de senha por e-mail e a alteração de senha pelo aplicativo não estão disponíveis nesta versão.
- As telas de pets exibem os dados cadastrais. Hospedagens e serviços ativos de cada pet não são exibidos. A lista de serviços nas cobranças mostra apenas os dados financeiros disponíveis.
- O perfil permite editar os dados de contato. Alteração de foto, central de notificações e preferências sem fluxo disponível foram omitidas das telas.
- Copiar códigos e baixar o PDF dependem dos dados do boleto retornados pela API. A tela sinaliza quando esses dados não estão disponíveis.
