Sistema para ajudar um petshop a organizar os serviços prestados aos clientes e acompanhar as respectivas cobranças.

## Visão geral

- Administradores podem gerenciar clientes, pets, serviços e cobranças.
- Clientes podem consultar suas cobranças e acompanhar os pagamentos.
- O sistema oferece suporte a pagamentos por boleto e ao acompanhamento de seus status.

## Tecnologia

O projeto contém uma API de back-end desenvolvida com Java e Spring Boot.

## Segurança

Este arquivo apresenta apenas uma visão geral. Não publique senhas, tokens, certificados, chaves privadas ou outros dados confidenciais no repositório. Configure dados privados apenas em ambientes locais ou serviços protegidos.
